## 发现的问题

无阻断性问题。

**设计建议**（非阻断，供开发阶段参考）：

1. **缓存键与 Java 版本的关系需明确**：`CompileCache` 结构体包含 `deps_hash` + `source_hash`，但未显式包含 `java_version` 字段。测试计划中提到"Java 版本变"应触发缓存失效。由于 `//JAVA 21` 写在源文件中，源码哈希变化自然会失效，但如果 `//JAVA` 行变更而实际 Java 源码未变（如仅改了版本声明行），仍然可以正确失效（因为文件内容变了）。建议在实现时确认：若 `//JAVA` 声明与当前系统 JDK 不匹配，是否应在运行时给出明确错误而非静默使用错误版本的 class 文件。
2. **设计核对点尚未勾选**：里程碑文档的 5 项设计核对点（shebang 格式兼容性、//DEPS 格式、缓存失效策略、错误处理、向后兼容）均为未勾选状态。建议在设计核对完成后逐一勾选，作为设计评审的闭环证据。
