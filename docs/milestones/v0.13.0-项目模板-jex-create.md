# v0.13.0: 项目模板（jex create）

## Context
前序阶段 v0.12.0 完成了生态互通（import pom），实现了 export/import 闭环。本阶段新增项目模板功能，帮助用户快速创建标准项目结构，降低 Java 项目上手门槛。
版本类型：minor（新增功能）

## 产品边界
**做什么**：
- `jex create` 命令支持多种项目模板
- 模板类型：web（Web 应用）、api（REST API）、cli（命令行工具）、lib（Java 库）
- 生成标准目录结构 + jex.toml + 示例代码
- 支持自定义模板名称和包名

**不做什么**：
- 不支持用户自定义模板（后续版本考虑）
- 不生成完整业务代码，只生成骨架
- 不支持模板市场

## 子任务详细设计

### 1 模板引擎核心
- **功能目标**：实现模板解析和文件生成逻辑
- **文件结构**：`crates/jex-core/src/template.rs`
- **接口设计**：
  - `pub fn create_project(name: &str, template: &str, package: Option<&str>) -> Result<()>`
  - `pub fn list_templates() -> Vec<TemplateInfo>`
  - `struct TemplateInfo { name, description }`
- **设计要点**：
  - 模板存储在内置（硬编码或 include_str!）
  - 支持变量替换（项目名、包名、日期）
  - 生成目录结构 + jex.toml + 示例 Java 文件
- **测试标准**：模板解析、变量替换、文件生成 3 个用例
- **提交信息**：`feat: add project template engine for jex create`

### 2 CLI 集成
- **功能目标**：注册 `jex create` 子命令
- **文件结构**：`crates/jex-cli/src/main.rs`
- **接口设计**：
  - `jex create <name> --template <type>`（默认 lib 模板）
  - `jex create --list` 列出可用模板
- **设计要点**：
  - CreateArgs 结构体
  - 默认模板为 lib
  - --list 参数列出所有模板
- **测试标准**：命令解析测试
- **提交信息**：`feat: add jex create CLI command with template selection`

### 3 模板文件
- **功能目标**：实现 4 种模板的目录结构和示例代码
- **模板类型**：
  - `lib`：基础 Java 库（src/Main.java + jex.toml）
  - `cli`：命令行工具（src/Main.java + jex.toml + 示例参数处理）
  - `api`：REST API（src/Main.java + jex.toml + 示例 HTTP 服务器）
  - `web`：Web 应用（src/Main.java + jex.toml + 示例 Web 框架）
- **设计要点**：
  - 每个模板包含：目录结构、jex.toml、示例 Java 文件
  - 示例代码可编译运行，展示基本功能
- **测试标准**：模板生成后可编译运行
- **提交信息**：`feat: add lib/cli/api/web project templates`

### 4 测试补充
- **功能目标**：补充 template 模块的测试用例
- **文件结构**：`crates/jex-core/src/template.rs`（tests 模块）
- **测试用例**：
  - 模板列表查询
  - 变量替换逻辑
  - 目录结构生成
  - jex.toml 生成
  - 示例代码生成
- **测试标准**：`cargo test` 全部通过
- **提交信息**：`test: add comprehensive tests for template module`
