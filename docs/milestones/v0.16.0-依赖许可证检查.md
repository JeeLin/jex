# v0.16.0: 依赖许可证检查

## Context
前序阶段 v0.15.0 完成了依赖安全检查（jex audit），帮助用户发现项目依赖中的已知安全漏洞。本阶段新增依赖许可证检查功能，帮助用户了解项目依赖的许可证类型和合规性，避免许可证冲突风险。
版本类型：minor（新增功能）

## 产品边界
**做什么**：
- `jex license` 检查项目依赖的许可证类型
- 显示许可证分布（MIT/Apache/GPL 等）
- 支持许可证合规性分析（检测 GPL 冲突）
- 支持 JSON 格式输出

**不做什么**：
- 不自动修改许可证（需用户手动处理）
- 不检查项目代码许可证（仅检查依赖）
- 不提供法律建议（仅提供信息）

## 子任务详细设计

### 1 许可证查询核心
- **功能目标**：实现依赖许可证查询和分析逻辑
- **文件结构**：`crates/jex-core/src/license.rs`
- **接口设计**：
  - `pub fn check_licenses() -> Result<Vec<LicenseInfo>>`
  - `pub fn analyze_compatibility(licenses: &[LicenseInfo]) -> ComplianceReport`
  - `struct LicenseInfo { group, artifact, version, license, spdx_id }`
  - `struct ComplianceReport { compatible, conflicts, warnings }`
- **设计要点**：
  - 读取 jex.lock.toml 获取项目依赖
  - 查询 Maven Central 获取依赖的 POM 文件
  - 从 POM 文件中提取许可证信息
  - 支持 SPDX 许可证标识符
- **测试标准**：许可证查询、合规性分析 2 个用例
- **提交信息**：`feat: add dependency license check with SPDX support`

### 2 CLI 集成
- **功能目标**：注册 `jex license` 子命令
- **文件结构**：`crates/jex-cli/src/main.rs`
- **接口设计**：
  - `jex license` 检查所有依赖许可证
  - `jex license --json` 输出 JSON 格式报告
  - `jex license --check` 仅检查合规性
- **设计要点**：
  - LicenseArgs 结构体（支持 --json 和 --check 标志）
  - 表格输出显示许可证分布
  - 颜色编码合规性状态
- **测试标准**：命令解析测试
- **提交信息**：`feat: add jex license CLI command with compliance check`

### 3 合规性分析
- **功能目标**：实现许可证合规性分析逻辑
- **文件结构**：`crates/jex-core/src/license.rs`
- **接口设计**：
  - 检测 GPL 与商业项目的冲突
  - 检测许可证互斥（如 MIT 和 GPL-3.0）
  - 生成合规性报告
- **设计要点**：
  - 定义许可证分类（宽松/弱 copyleft/强 copyleft）
  - 实现冲突检测规则
  - 生成详细的合规性报告
- **测试标准**：GPL 冲突检测、许可证互斥检测 2 个用例
- **提交信息**：`feat: implement license compatibility analysis with conflict detection`
