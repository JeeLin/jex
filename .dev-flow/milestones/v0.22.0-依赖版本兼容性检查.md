# v0.22.0: 依赖版本兼容性检查

## Context
前序阶段 v0.21.0 完成了依赖许可证自动检查（jex license-check），在添加依赖时自动检查许可证合规性。本阶段新增依赖版本兼容性检查功能，检查项目依赖之间的版本兼容性，帮助用户避免版本冲突。
版本类型：minor（新增功能）

## 产品边界
**做什么**：
- `jex check` 检查项目依赖版本兼容性
- 显示版本冲突和不兼容警告
- 提供版本升级建议

**不做什么**：
- 不自动修复版本问题（仅检测和报告）
- 不修改依赖版本（仅检查）
- 不提供依赖咨询（仅显示信息）

## 子任务详细设计

### 1 版本兼容性检查核心
- **功能目标**：实现依赖版本兼容性检查逻辑
- **文件结构**：`crates/jex-core/src/compat_check.rs`
- **接口设计**：
  - `pub fn check_compatibility() -> Result<CompatibilityReport>`
  - `struct CompatibilityReport { compatible, conflicts, warnings }`
- **设计要点**：
  - 解析 Cargo.lock 中的依赖版本
  - 检查依赖之间的版本约束冲突
  - 生成兼容性报告
- **测试标准**：检查、报告 2 个用例
