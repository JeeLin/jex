# v0.12.0: 生态互通（import pom）

## Context
前序阶段 v0.11.0 完成了 CLI 增强（build/analyze/repl/completions）。本阶段完成 export/import 闭环的最后一块：从 pom.xml 导入依赖到 jex.toml，使 Maven 项目能低成本迁移到 jex。
版本类型：minor（新增功能）

## 产品边界
**做什么**：
- 从 pom.xml 解析依赖列表（支持 dependencyManagement 版本继承）
- 过滤非 compile scope 依赖（test/provided/system 跳过）
- 将 Maven 坐标转换为 jex 格式（group:artifact:version）
- 与现有 jex.toml 合并（版本冲突时保留现有版本并提示）
- CLI 命令 `jex import maven`（别名 `jex i`）

**不做什么**：
- 不处理 exclusions/transitive 依赖（有损导入，与 export 对称）
- 不双向同步 pom.xml 和 jex.toml
- 不自动下载依赖（仅写入 jex.toml）

### 1 pom.xml 解析引擎
- **功能目标**：用 quick-xml 解析 pom.xml，提取 `<dependencies>` 区块内的依赖
- **文件结构**：`crates/jex-core/src/import.rs`
- **接口设计**：`pub fn parse_pom(path: &Path) -> Result<Vec<PomDependency>>`
- **设计要点**：
  - 支持 dependencyManagement 版本继承（无版本号时从 management 区块查找）
  - 跳过 dependencyManagement 内的依赖（只处理顶层 dependencies）
  - PomDependency 结构体：group_id, artifact_id, version, scope
- **测试标准**：简单 pom、dependencyManagement 继承、scope 过滤、空 pom 4 个用例
- **提交信息**：`feat: add jex import maven command with pom.xml parsing, coordinate conversion, and dependency merging`

### 2 坐标转换与 scope 过滤
- **功能目标**：将 PomDependency 转换为 jex 坐标字符串，过滤非 compile 依赖
- **文件结构**：`crates/jex-core/src/import.rs`
- **接口设计**：`pub fn pom_to_jex_coords(deps: &[PomDependency]) -> Vec<String>`
- **设计要点**：
  - 无版本号的依赖跳过（打印警告）
  - scope 过滤：只保留 compile（无 scope 或 scope=compile）
  - 坐标格式：`group:artifact:version`
- **测试标准**：坐标转换测试

### 3 依赖合并与冲突处理
- **功能目标**：将导入的依赖与现有 jex.toml 合并，处理版本冲突
- **文件结构**：`crates/jex-core/src/import.rs`
- **接口设计**：`pub fn merge_with_existing(imported: &[String], existing: &HashMap<String, String>) -> HashMap<String, String>`
- **设计要点**：
  - 版本冲突时保留现有版本，打印警告提示
  - 新依赖追加，已有依赖不覆盖
- **测试标准**：无冲突合并、版本冲突处理 2 个用例

### 4 CLI 集成与测试
- **功能目标**：注册 `jex import` 子命令，支持自定义 pom.xml 路径
- **文件结构**：`crates/jex-cli/src/main.rs`（ImportArgs + Commands::Import）
- **接口设计**：
  - `jex import maven [path]`（默认当前目录 pom.xml）
  - 别名：`jex i`
- **设计要点**：
  - 读取现有 jex.toml（不存在时创建新配置）
  - 调用 import_maven() 完成完整流程
  - 输出导入结果摘要（添加数/总数/冲突警告）
- **测试标准**：集成测试通过
