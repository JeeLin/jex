# v0.17.0: 依赖树可视化

## Context
前序阶段 v0.16.0 完成了依赖许可证检查（jex license），帮助用户了解项目依赖的许可证类型和合规性。本阶段新增依赖树可视化功能，帮助用户以树状结构查看项目依赖的层级关系，便于理解依赖结构和排查冲突。
版本类型：minor（新增功能）

## 产品边界
**做什么**：
- `jex tree` 显示项目依赖树结构
- 支持深度限制（--depth N）
- 支持 JSON 格式输出（--json）
- 显示依赖版本和许可证信息

**不做什么**：
- 不修改依赖树（仅展示）
- 不显示传递依赖的详细信息（仅显示层级）
- 不支持图形化界面（仅终端输出）

## 子任务详细设计

### 1 依赖树解析
- **功能目标**：实现依赖树解析和展示逻辑
- **文件结构**：`crates/jex-core/src/tree.rs`
- **接口设计**：
  - `pub fn build_dependency_tree() -> Result<DependencyTree>`
  - `pub fn render_tree(tree: &DependencyTree, depth: Option<usize>) -> String`
  - `struct DependencyTree { root, children }`
  - `struct DependencyNode { name, version, children, license }`
- **设计要点**：
  - 读取 jex.lock.toml 获取项目依赖
  - 解析依赖关系构建树结构
  - 支持深度限制和格式化输出
  - 集成许可证信息（从 license.rs 获取）
- **测试标准**：树构建、深度限制 2 个用例
- **提交信息**：`feat: add dependency tree visualization with depth limit`

### 2 CLI 集成
- **功能目标**：注册 `jex tree` 子命令
- **文件结构**：`crates/jex-cli/src/main.rs`
- **接口设计**：
  - `jex tree` 显示完整依赖树
  - `jex tree --depth N` 限制显示深度
  - `jex tree --json` 输出 JSON 格式
- **设计要点**：
  - TreeArgs 结构体（支持 --depth 和 --json 标志）
  - 终端树状输出（使用 Unicode 字符）
  - 颜色编码不同层级
- **测试标准**：命令解析测试
- **提交信息**：`feat: add jex tree CLI command with depth and JSON support`

### 3 测试补充
- **功能目标**：补充 tree 模块的测试用例
- **文件结构**：`crates/jex-core/src/tree.rs`（tests 模块）
- **测试用例**：

  - 深度限制
