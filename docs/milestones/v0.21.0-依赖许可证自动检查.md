# v0.21.0: 依赖许可证自动检查

## Context
前序阶段 v0.20.0 完成了依赖缓存管理（jex cache），帮助用户清理、查看和管理项目依赖缓存。本阶段新增依赖许可证自动检查功能，在添加依赖时自动检查许可证合规性，帮助用户避免引入不兼容的许可证。
版本类型：minor（新增功能）

## 产品边界
**做什么**：
- `jex add` 时自动检查新依赖的许可证
- `jex license --check` 手动检查所有依赖的许可证合规性
- 显示许可证合规性报告（兼容/不兼容/未知）
- 支持自定义许可证白名单

**不做什么**：
- 不自动修复许可证问题（仅检测和报告）
- 不修改依赖版本（仅检查许可证）
- 不提供许可证咨询（仅显示信息）
