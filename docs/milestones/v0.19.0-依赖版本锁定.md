# v0.19.0: 依赖版本锁定

## Context
前序阶段 v0.18.0 完成了项目依赖分析报告（jex report），帮助用户全面了解项目依赖状况。本阶段新增依赖版本锁定功能，帮助用户锁定特定依赖版本，避免意外升级导致兼容性问题。
版本类型：minor（新增功能）

## 产品边界
**做什么**：
- `jex pin` 锁定指定依赖的版本
- `jex pin --all` 锁定所有依赖版本
- 显示当前锁定状态
- 支持解锁指定依赖

**不做什么**：
- 不修改依赖版本（仅锁定/解锁）
- 不提供版本推荐（仅锁定当前版本）
- 不支持自动锁定策略（仅手动操作）

## 子任务详细设计

### 1 版本锁定核心
- **功能目标**：实现依赖版本锁定和解锁逻辑
- **文件结构**：`crates/jex-core/src/pin.rs`
- **接口设计**：
  - `pub fn pin_dependency(coord: &str) -> Result<()>`
  - `pub fn pin_all() -> Result<()>`
  - `pub fn unpin_dependency(coord: &str) -> Result<()>`
  - `pub fn list_pinned() -> Result<Vec<PinnedDep>>`
  - `struct PinnedDep { coord, version, pinned_at }`
- **设计要点**：
  - 读取 jex.lock.toml 获取当前依赖版本
  - 写入 jex.pin.toml 记录锁定的依赖
  - 解锁时从 jex.pin.toml 移除对应条目
  - 支持显示锁定状态
- **测试标准**：锁定、解锁、列表 3 个用例
- **提交信息**：`feat: add dependency version pinning with jex pin`

### 2 CLI 集成
- **功能目标**：注册 `jex pin` 子命令
- **文件结构**：`crates/jex-cli/src/main.rs`
- **接口设计**：
  - `jex pin <coord>` 锁定指定依赖
  - `jex pin --all` 锁定所有依赖
  - `jex pin --list` 显示锁定状态
  - `jex pin --unpin <coord>` 解锁指定依赖
- **设计要点**：
  - PinArgs 结构体（支持 coord、--all、--list、--unpin 标志）
  - 终端友好的状态输出
  - 颜色编码锁定状态
- **测试标准**：命令解析测试
- **提交信息**：`feat: add jex pin CLI command with list and unpin support`

### 3 测试补充
