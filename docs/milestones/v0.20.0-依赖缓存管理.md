# v0.20.0: 依赖缓存管理

## Context
前序阶段 v0.19.0 完成了依赖版本锁定（jex pin），帮助用户锁定特定依赖版本避免意外升级。本阶段新增依赖缓存管理功能，帮助用户清理、查看和管理项目依赖缓存，释放磁盘空间并解决依赖冲突问题。
版本类型：minor（新增功能）

## 产品边界
**做什么**：
- `jex cache clean` 清理项目依赖缓存
- `jex cache list` 显示缓存内容和大小
- `jex cache path` 显示缓存目录路径
- 支持指定清理范围（项目缓存、全局缓存）

**不做什么**：
- 不自动清理缓存（仅手动操作）
- 不修改依赖版本（仅管理缓存）
- 不提供缓存策略配置（仅基础管理）

### 1 缓存管理核心
- **功能目标**：实现依赖缓存清理、列表和路径查询逻辑
- **文件结构**：`crates/jex-core/src/cache.rs`
- **接口设计**：
  - `pub fn clean_cache(global: bool) -> Result<()>`
  - `pub fn list_cache() -> Result<Vec<CacheEntry>>`
  - `pub fn cache_path() -> Result<PathBuf>`
  - `struct CacheEntry { name, size, modified }`
- **设计要点**：
  - 查找 Coursier 缓存目录（~/.cache/coursier 或 ~/.coursier/cache）
  - 计算缓存大小和条目数
  - 清理时显示进度和释放空间
  - 支持项目级和全局级缓存清理
- **测试标准**：清理、列表、路径 3 个用例
