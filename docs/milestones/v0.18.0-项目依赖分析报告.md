# v0.18.0: 项目依赖分析报告

## Context
前序阶段 v0.17.0 完成了依赖树可视化（jex tree），帮助用户以树状结构查看项目依赖层级。本阶段新增项目依赖分析报告功能，整合现有的依赖管理工具（outdated、audit、license、tree），生成一份综合分析报告，帮助用户全面了解项目依赖状况。
版本类型：minor（新增功能）

## 产品边界
**做什么**：
- `jex report` 生成项目依赖综合分析报告
- 整合 outdated、audit、license、tree 的分析结果
- 支持 JSON 格式输出（--json）
- 终端友好的格式化输出

**不做什么**：
- 不修改依赖（仅分析）
- 不提供自动修复建议（仅展示信息）
- 不支持自定义报告模板（仅内置格式）

### 1 报告生成核心
- **功能目标**：实现依赖分析报告生成逻辑
- **文件结构**：`crates/jex-core/src/report.rs`
- **接口设计**：
  - `pub fn generate_report() -> Result<DependencyReport>`
  - `pub fn render_report(report: &DependencyReport) -> String`
  - `struct DependencyReport { summary, outdated, vulnerabilities, licenses, tree }`
  - `struct ReportSummary { total, outdated_count, vulnerability_count, license_issues }`
- **设计要点**：
  - 调用 outdated::check_outdated() 获取可更新依赖
  - 调用 audit::check_vulnerabilities() 获取漏洞信息
  - 调用 license::check_licenses() 获取许可证信息
  - 调用 tree::build_dependency_tree() 获取依赖树
  - 整合所有结果生成综合报告
- **测试标准**：报告生成、格式化输出 2 个用例
- **提交信息**：`feat: add dependency analysis report generation`
